An entry for the [One Line, One Laugh bounty](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3): a single sentence that tries to earn a laugh out of the most ordinary Sunday habit going wrong.

## The line

> I tried meal-prepping on Sunday and by Wednesday the containers had unionised against me.

The humour comes from the distance between the Sunday plan and the Wednesday reality: a tidy afternoon of cooking, then a fridge that feels like it has filed a formal complaint.

## How to run

Requires Node 22 or newer. No dependencies are needed, and the program never touches the network.

```sh
node main.ts
```

By default it writes `entry.txt` into `/output`. To point it somewhere else, set `MAKEFUN_OUTPUT_DIR` before running:

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

The output is always the same line followed by a single trailing newline, so every run produces an identical file.
